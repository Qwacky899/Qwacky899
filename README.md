## How I approach a game

- **Clarity before complexity:** players should understand an interaction before they have to think about it.
- **Mobile is first-class:** responsive UI and touch interaction are designed in from the beginning.
- **Systems should scale:** reusable architecture and clean content pipelines matter as much as the first release.
- **Polish should serve the product:** visual quality, retention and commercial goals should reinforce each other.
